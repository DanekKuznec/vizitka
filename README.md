# Даниил — сайты и чат-боты

Сайт-визитка: работы, услуги, порядок работы и контакты.

- Скриншоты работ прокручиваются внутри окна браузера при наведении, на телефоне их можно листать пальцем.
- Запись экрана бота играет только пока видна на экране.
- Блоки плавно появляются при прокрутке; если в системе включено «уменьшить движение», анимации отключаются.

Один файл `index.html` без фреймворков, картинки и видео в `media/`.
